# scoop-osf

Project-owned Scoop bucket for [OSF CLI Go](https://github.com/edithatogo/osf-cli-go).

```powershell
scoop bucket add osf https://github.com/edithatogo/scoop-osf
scoop install osf-cli-go
osf --version
```

The manifest uses the signed v0.3.2 Windows release assets and their SHA-256
checksums, with GitHub-based version checks and automatic update URLs.
